# 🏃‍♂️ Trim Track

**Trim Track** is a responsive frontend-based health and fitness web application designed to help users monitor their fitness journey through BMI calculation, calorie estimation, and health awareness tools. The platform provides an intuitive user experience with modern UI components, dark/light mode support, and personalized health utilities.

---

## 📖 Overview

Maintaining a healthy lifestyle requires awareness of important health metrics such as Body Mass Index (BMI), daily calorie requirements, and healthy habits. Trim Track aims to provide users with quick and accessible tools to assess these metrics while offering useful fitness and wellness guidance.

The application is built entirely using frontend technologies and focuses on simplicity, responsiveness, and user experience.

## 🚀 How to Run the Project

### Method 1: Direct Execution

1. Download or clone the repository.

```bash
git clone https://github.com/Kart-1692/TrimTrack.git
```

2. Navigate to the project directory.

```bash
cd TrimTrack
```

3. Open `index.html` in any modern web browser.

---

### Method 2: Using VS Code Live Server

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.

The application will launch automatically in your browser.
